## Описание проекта

Репозиторий создан как fork учебного репозитория
[BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC) и используется для
выполнения лабораторных работ по дисциплине.

Создаваемый проект (вариант 12) — **приложение «Астролог»**. Пользователь
вводит дату рождения (день, месяц и год в текстовых полях, без стандартного
элемента выбора даты), программа определяет знак Зодиака и выводит
астрологическую информацию о нем. Приложение с графическим интерфейсом на
C++ (Windows API) строится по паттерну MVC с активной моделью: модель сама
оповещает представление об изменениях.

В репозитории последовательно выполняются этапы жизненного цикла продукта:

1. анализ и спецификация требований (SRS) — по шаблонам из папки `srs/`;
2. проектирование архитектуры (SDD) и фиксация архитектурных решений (ADR) —
   по шаблонам из папок `sdd/` и `adr/`;
3. разработка программного обеспечения — в папке `project/`;
4. тестирование, сборка и сопровождение.

Проект в папке `project/` — пустой шаблон проекта Visual Studio Code на C++17,
в котором в дальнейшем будет выполняться проектирование и разработка задания.

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `project/` | Проект Visual Studio Code (C++17), в котором ведется разработка |
| `project/src/` | Исходный код (*.cpp) |
| `project/include/` | Заголовочные файлы (*.h) |
| `project/tests/` | Модульные тесты |

| `.gitignore` | Временные файлы и папки, не попадающие в репозиторий |

## Сборка и запуск

Требуется компилятор GCC (MinGW-w64) с отладчиком GDB. Проект открывается в
Visual Studio Code командой File → Open Folder (папка `project`) и собирается
сочетанием Ctrl+Shift+B или из командной строки:

```bash
cd project
mkdir -p build
g++ -std=c++17 -Iinclude src/*.cpp -o build/Zodiac.exe
./build/Zodiac.exe
```
